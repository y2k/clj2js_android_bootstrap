# Правила работы

- По умолчанию выполняй работу непосредственно в ветке `master`, в текущем рабочем каталоге. Создавай отдельную ветку или worktree только по явному указанию пользователя.
- По умолчанию выполняй все задачи самостоятельно, без субагентов, кроме ревью. Используй субагентов только по явному указанию пользователя.
- Создавай комиты только по явному требованию пользователя. Без такого требования комиты запрещены; оставляй изменения незакоммиченными.
